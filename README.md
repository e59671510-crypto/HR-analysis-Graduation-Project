# HR Analytics

**Prepared by: Eslam Ayman Ezzat

* Goal of Analysis
Analyze HR operational data to understand employee attrition and exit drivers, evaluate overtime workload versus absenteeism, review salary structures and pay band alignment, and track compensation and bonus distribution across branches.

* Tools used
- **Microsoft Excel:** Data cleaning with Power Query, pivot aggregations, and interactive summary dashboards.
- **Power BI:** Relational data modeling, custom DAX measures, and executive reporting views.
- **Tableau Public:** Logical layer modeling, HR charts, and an interactive Story ([View on Tableau Public](https://public.tableau.com/app/profile/eslam.ayman4608/viz/tabluegraduationproject/HRWorkforceAttendancePerformanceCompensationAnalysis?publish=yes))[cite: 14].
